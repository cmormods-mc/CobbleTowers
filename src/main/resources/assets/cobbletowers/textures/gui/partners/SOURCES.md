# Partner sprites

`blastoise.png`, `machamp.png` and `scizor.png` were here first. The rest (48x32 entity icons used on the modifier cards) were
copied unchanged from the **Cobblemon Cards** mod, jar `cobblemon-cards-fabric-1.0.4`, path
`assets/cobblemon-cards/textures/item/cards/pokemon/entity_icon/<dex>_<name>/<name>.png`.

- Source: https://github.com/Howlite-UI/CobblemonCards
- Licence: **CC0 1.0 Universal** (the jar's `fabric.mod.json` says `CC0-1.0`; the owner of this repository confirmed it). No
  attribution is required; the source is recorded here anyway.
- Extracted with a one-off script: the plain (non-shiny, ungendered) icon of each species named in `ModifierScene`.
