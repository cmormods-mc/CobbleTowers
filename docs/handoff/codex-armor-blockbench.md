# Handoff: real armor art for CobbleTowers (Blockbench)

Task: replace the generated placeholder art for all 12 armor sets (48 pieces) with hand-made art built in Blockbench. No Java or data changes are needed. Only PNG files are replaced, under the same names.

## What exists

Minecraft 1.21.1, Fabric. Armor is vanilla-style humanoid armor: each set has two worn-layer textures and four 16x16 inventory icons. The art is currently generated by `tools/generate_armor_art.py` (palette-based pixel shapes).

Paths (all under `src/main/resources/assets/cobbletowers/`):

| File | Size | Holds |
|---|---|---|
| `textures/models/armor/<set>_layer_1.png` | 64x32 | helmet + chestplate (body, arms) + boots |
| `textures/models/armor/<set>_layer_2.png` | 64x32 | leggings only |
| `textures/item/<set>_<slot>.png` | 16x16 | inventory icon; slot is `helmet`, `chestplate`, `leggings` or `boots` |
| `models/item/<set>_<slot>.json` | n/a | `minecraft:item/generated`, layer0 = the icon. Leave as is |

Vanilla humanoid armor UV layout on the 64x32 sheets: head (0,0) 32x16, legs/boots (0,16) 16x16, body (16,16) 24x16, arms (40,16) 16x16. The rest of the sheet stays transparent.

Trims: `textures/trims/models/armor` holds trim overlays. If a worn texture's silhouette changes a lot, check a trim in game. Do not edit trim files unless something looks wrong.

## How to work

1. In Blockbench use the "Modded Entity" or "Skin" template for a humanoid armor layout, or open a vanilla armor texture (`textures/models/armor/<material>_layer_1.png`) as the UV reference. Paint on the 64x32 sheet. Keep the vanilla UV islands; the game maps them to the player model.
2. Export each sheet as PNG to the exact filename above, replacing the placeholder. Keep transparency where nothing belongs.
3. Paint the 16x16 icons separately (flat, readable at small size, outline + 3 shades + accent).
4. Do one set at a time. Suggested order: the four tier III sets (the chase), then tier I, then tier II.
5. `python tools/preview_armor_art.py` renders a contact sheet (`armor_preview.png` at the repo root) for a quick look without launching the game.

## Rules

- Same filenames, same sizes, PNG with alpha. Do not rename, add or remove files; ids are registered in Java (`ArmorSetItems.SETS`) and the tests check that every file exists.
- Do not run `tools/generate_armor_art.py` after replacing art: it would overwrite your work.
- Do not touch `armor_sets/*.json` (bonuses), reward tables or Java.
- Commit message style: short, plain. No attribution or co-author lines.

## Checks before handing back

- Size check (Pillow): every `models/armor/*_layer_*.png` is 64x32, every `item/*_<slot>.png` is 16x16.
- `./gradlew test --tests "*ArmorSetTest" --tests "*SeasonTrimAssetsTest"` passes (files exist, all 48 pieces trimmable). Do not build while a push is in progress.
- The owner looks at the pieces in a real client; none of the 32 P38 pieces has been seen there yet.
