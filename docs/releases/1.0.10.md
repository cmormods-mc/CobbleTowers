# CobbleTowers 1.0.10

Combines the loot/daily exploit changes from `5561ff4` and `1516f73` with the battle, rental recovery, spectator and WebUI fixes previously tested in the local 1.0.9 build.

- Preserve scored-attempt-only daily/weekly trial payouts, practice-run rental-key chance, daily completion budget, revised loot rolls, armor duplicate protection and enemy level scaling from the pushed branch.
- Defer entity cleanup safely and end owned battles when players leave or runs terminate.
- Recover original parties across rental exits and interrupted restoration.
- Clear owned spectator HUD state and separate overlapping revived players using safe landing positions.
- Contain and scroll large reward lists; prevent extended route previews from overlapping their labels.
- Use canonical `webgui://` page URLs, including normalization of the legacy `webgui:/` spelling in existing Tower configs.
- Compile against the CobbleRaids 0.8.190 API published by its current main branch, matching the CI dependency checkout.

The original report of a completely black world after a victory remains unconfirmed. These fixes do not establish that its cause has been identified. The temporary client probe and battle driver are not part of this release.
